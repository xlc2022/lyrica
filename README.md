# Lyrica

A continuous personal companion built on [Pi](https://github.com/badlogic/pi-mono).

This repository is being restarted from scratch. No code exists yet. We are
agreeing on [design principles](PRINCIPLES.md) first and recording settled
choices in [DECISIONS.md](DECISIONS.md).

Lyrica runs for one person on one server. Anyone with a shell on that server
can read everything she stores.
